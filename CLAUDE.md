# rosterwise.app — Marketing & Content Site

The public marketing/content website for **RosterWise™**, a college-sports
recruiting-intelligence product for recruits and their families. Domain:
**rosterwise.app**. Company: **Grobe Games LLC**. This is the SEO/content
front door — deep per-sport recruiting guides plus programmatically generated
program pages that rank for "[School] [Gender] [Sport]" searches and funnel
families to the iOS apps.

Part of the Rosterwise product family. For cross-repo/family context (pipeline,
shared iOS core, per-sport apps) see the umbrella `~/Code/rosterwise/CLAUDE.md`.
This repo is its own git remote: `GrobeGames/rosterwise.app`, default branch
`main`.

## Tech stack

- **Eleventy (11ty) v3** static site generator (`.eleventy.js`).
- Templates: **Nemjucks (`.njk`)** — `htmlTemplateEngine` and
  `markdownTemplateEngine` are both `njk`. Content is a mix of `.njk`, `.md`,
  and `.html`.
- Markdown pipeline: `markdown-it` + `markdown-it-anchor` (header anchors) +
  `markdown-it-toc-done-right` (auto TOC, `.toc` container).
- No client framework, no CSS build step — plain CSS in `src/assets/`,
  passthrough-copied.
- Deployed via **Cloudflare Pages**, auto-deploy on every push to `main`.

## Build & serve

```bash
npm run build          # eleventy build → _site, then generate-sitemap, then check-seo
npx @11ty/eleventy --serve   # local dev server with live reload
npm run generate-sitemap     # regenerate _site/sitemap.xml from built HTML
npm run check-seo            # assert robots.txt + sitemap.xml exist and are valid
```

- **Input:** `src/`  →  **Output:** `_site/` (git-ignored). Includes dir:
  `src/_includes/`. (Note: the README's "output directory: `.`" line is stale —
  Eleventy and the sitemap script both use `_site/`.)
- `npm run build` fails the build (non-zero exit) if `check-seo` finds
  robots.txt / sitemap.xml missing or the sitemap doesn't reference
  `https://rosterwise.app` — keep it green.

## Content architecture

- `src/_includes/` — layouts: `base.njk` (HTML shell + all SEO meta),
  `content.njk`, `hub.njk`, `product.njk`, `sidebar.njk`, `blog-post.njk`,
  `us-map.njk`, `app-logos.njk`.
- **Sport-agnostic guides:** `src/guide/` — general recruiting guides
  (timeline, eligibility, scholarships, transfer portal, NIL, visits, …).
- **Per-sport content:** `src/{soccer,lacrosse,volleyball,wrestling}/` — each
  with `mens/` and `womens/` subtrees containing `guide/`, `methodology/`, and
  (soccer) `programs/` hubs. E.g. `/soccer/mens/guide/recruiting-timeline/`.
- **Program pages (programmatic SEO):** `src/program-pages.njk` paginates over
  `src/_data/programs.json` (one page per program via
  `permalink: "{{ program.page_url }}"`), with per-page `title_tag`,
  `meta_description`, `h1`, and Article JSON-LD. Program hub pages
  (`/soccer/mens/programs/`, `/soccer/womens/programs/`) offer client-side
  filtering.
- `programs.json` is **generated by the pipeline**, not hand-edited here. Regen:
  `PYTHONPATH=src uv run python scripts/export_web_programs.py --output ../rosterwise.app/src/_data/programs.json` (run from the `pipeline/` repo).
- Legal: `src/{privacy,takedown,disclaimer,support,terms}/`. Blog: `src/blog/`.

## SEO conventions (durable rules)

- **All SEO meta lives in `base.njk`** — title, description, canonical, Open
  Graph, Twitter card, favicons, GA4 (`G-JDNR1HSPHW`), and Organization JSON-LD.
  Canonical/OG URLs are `https://rosterwise.app{{ page.url }}`. New page types
  set `title` / `description` (and optional `og_*`) in front matter.
- **External links MUST go through the `absUrl` filter** (`.eleventy.js`). A
  schemeless external href (e.g. `hiuroyals.com`) resolves relative to
  rosterwise.app and creates bogus same-site crawl URLs → soft-404s in Search
  Console. Always `{{ someDomain | absUrl }}` for outbound links.
- **`src/404.html` must exist.** Cloudflare Pages auto-serves it with a real
  HTTP 404 for unmatched paths; without it, unmatched URLs return the homepage
  with HTTP 200 (SPA-style fallback), which manufactures soft-404 "alternate"
  pages. The 404 page is `noindex`.
- **Sitemap** is auto-generated from built HTML in `_site/` by
  `scripts/generate-sitemap.js`. Add priority/changefreq rules for new page
  types by editing its `PATH_CONFIG` array (first match wins — specific before
  catch-all); exclude files via `EXCLUDE_FILES` / `EXCLUDE_PATTERNS`.
- **Clean URLs & redirects:** `src/_redirects` (Cloudflare) handles clean URLs
  and legacy 301s (`/terms` → `/privacy/`). Cloudflare issues 308s for
  trailing-slash canonicalization — footers link with trailing slashes to avoid
  redirect hops. `src/robots.txt` disallows `/terms`, `/admin/`, `/_build/`,
  `/blog/feed.xml` and points to the sitemap.
- Passthrough-copied as-is (see `.eleventy.js`): `src/assets/`, `robots.txt`,
  `_redirects`, `_headers`.
